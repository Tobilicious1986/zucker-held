# Zucker-Held Doku-Index

Dieser Ordner bündelt die ausführliche Projekt-, Agenten-, Sprint- und Review-Dokumentation. Die Root-Dateien `../AGENTS.md` und `../CLAUDE.md` bleiben als kurze Einstiegspunkte bestehen, damit KI-Tools sie automatisch finden.

## Struktur
- `agents/` — verbindliche KI-/Agentenregeln, Branching, Sprint-Workflow
- `project/` — Architektur, Backlog, Cookbook, Produktstrategie, ADRs und Systemreview
- `sprints/` — laufende Sprint-Lagebilder
- `reviews/` — Sprint-, Specialist-, UI/UX- und UAT-Reviews
- `uat/` — UAT-Testpläne

## Pflicht-Einstiege für Agenten
- Allgemeine Regeln: `agents/PROJECT_RULES.md`
- Git/Branching: `agents/BRANCHING.md`
- Sprint-/Daily-/Review-Logik: `agents/AGENT_WORKFLOW.md`
- Architektur: `project/ARCHITECTURE.md`
